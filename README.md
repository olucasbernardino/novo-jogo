# Embervale

RPG 2D em canvas (estilo Tibia), um único arquivo: `index.html`. Classes: Mage, Necromancer e Herb Gardener (saves separados).

## Jogar
- Online (GitHub Pages): https://olucasbernardino.github.io/novo-jogo/
- Local: baixe o repositório e abra `index.html` no navegador (não precisa de servidor nem build).

## Pastas
- `index.html` – o jogo completo (sprites da Herb embutidos).
- `psy_efeitos_herb.js` – código-fonte dos feitiços psicodélicos (já embutido no index).
- `sprites/atlas/` – atlas atual da Herb; `sprites/herb_originais/` – spritesheets e referências enviadas.
- `mockups/` – poderes, batalha isométrica, 3 estilos, canvas de design.
- `scripts/` – testes Playwright e utilitários; `docs/` – notas.
